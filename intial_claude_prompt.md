Create a desktop (GUI) application that runs on Mac and Windows (and possible Linux) including a CLI that can inspect/explorer all the typical files stored in an Android or iOS application's file structure. Since this is cross-platform (Windows, Mac, and potentially Linux in the future), use the best famework possible, either Flutter or seperate frameworks with seperate thick-clients (i.e., .NET, Mac-native, GNU, etc.). The project should be able perform the following:
- The application should begin in a wizard workflow but allow exiting to an advanced option (all should allow to the GUI and CLI)
- Allow the user to specific Android or iOS for the file folder system type
- Provide any necessary credentials/IP/port information
- Interact with attached devices, emulators, or communication over TCP bridges
- Allow native shell/SSH/console access to the the devices file system
- Detect active Android/iOS devices (i.e., adb, emulators, USB, TCP, etc.)
- Specify the installed application being targeted on the device
- Copy the file structure of the application to a location specified
- Search/identify any secrets patterns (such as those identified by the Trufflehog tool...and more) stored in any files
- Allow users to supply a file of know secrets to look for
- Load two or more different file roots (i.e., iOS/Android logged in files vs. logged out files) and perform a diff on them at a native-level (database, binary, XML, config, etc.)
- Load/mount database (e.g., SQLITE, etc.) files to be viewed locally
- Render all common Android/iOS native file types (XML, web caches, databases, config, etc.), especially any propriatary Android/iOS file types
- Summarize results into actionable reports
